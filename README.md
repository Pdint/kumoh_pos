# 🍢 금오분식 POS 시스템

분식집 **금오분식**을 위한 GUI 기반 POS(Point-Of-Sale) 프로그램입니다.
테이블·포장 주문, 분할 결제, 할인·회원 포인트, 레시피 기반 재고, 주방 화면, 예약, 직원 급여, 매출 통계, 일일 마감까지 지원합니다.

- 언어: **Python 3.9+** (표준 라이브러리만 사용 — 별도 설치 불필요)
- GUI: **Tkinter**
- 저장소: **SQLite** (`data/pos.db`)

📄 요구사항 구현 현황 · 제한사항 · 확장 기능 정리 → [`docs/요구사항명세.md`](docs/요구사항명세.md)

![주문 화면](docs/images/order.png)

## 실행 방법

```bash
python main.py                # 실행 (처음 실행 시 기본 메뉴/재료/테이블/직원 자동 생성)
python main.py --demo 60      # 최근 60일치 샘플 판매 데이터를 만들고 실행 (통계 시연용)
python main.py --db test.db   # 다른 DB 파일로 실행
```

- 관리자 비밀번호 초기값: **`0000`** (설정 화면에서 변경)
- Windows/macOS의 공식 Python에는 Tkinter가 포함되어 있습니다. Linux는 `sudo apt install python3-tk`.

테스트 실행:

```bash
python -m unittest discover -s tests -v
```

## 사용 흐름 예시

1. **주문**: 테이블(T1~T8) 클릭 → 메뉴 버튼 클릭(누를 때마다 1개 추가) → 오른쪽에서 수량 조정
2. **포장**: 왼쪽 아래 `+ 새 포장 주문` → 메뉴 추가 → 결제 → 조리 완료 후 `픽업 완료`
3. **결제**: `결제` → (선택) 회원 조회·쿠폰·포인트 → 결제 방식(전체/금액 분할/메뉴별 분할) → 결제 수단 → `결제하기` → 영수증 종류 선택
4. **주방**: `주방` 탭에서 메뉴 선택 후 `조리 완료` → 처리 시간 통계에 반영
5. **마감**: 관리자 모드 → `일일 마감` → `일일 마감 실행` (미결제 주문이 없어야 함)

## 프로젝트 구조

```
main.py                    실행 진입점
pos/
  config.py                가게 정보 · 제한사항 상수
  db.py                    SQLite 스키마 · 초기 데이터 · 비밀번호 해시
  system.py                서비스들을 묶는 PosSystem
  demo.py                  샘플 판매 데이터 생성기
  services/                ── 비즈니스 로직 (GUI와 독립, 단위 테스트 대상)
    menu.py                  메뉴 · 분류 · 재료 · 레시피 · 재고 차감/품절
    table.py                 테이블
    order.py                 주문 추가/변경/삭제 · 테이블 병합/분할 · 주방
    discount.py              메뉴/시간대/쿠폰 할인 · 금액 계산
    payment.py               결제 · 분할 결제 · 환불
    member.py                회원 · 등급 · 포인트
    staff.py                 근태 · 급여
    reservation.py           예약 주문
    stats.py                 통계
    report.py                영수증 · 일일 마감 · CSV · 백업
    auth.py                  모드 전환 · 관리자 인증
  gui/                     ── Tkinter 화면
    app.py                   메인 윈도우 · 탭 · 예약 알림 · 출퇴근
    order_view.py            주문 화면
    payment_dialog.py        결제 창
    kitchen.py               주방 화면
    reservation_view.py      예약
    member_view.py           회원
    stats_view.py            통계(막대 그래프)
    admin_views.py           관리자 화면들
    widgets.py               공용 위젯
tests/test_pos.py          단위 테스트
docs/요구사항명세.md        요구사항 · 제한사항 · 확장 기능
```

실행 중 생성되는 폴더: `data/`(DB), `receipts/`(영수증), `reports/`(마감 보고서), `exports/`(CSV), `backups/`(백업)
