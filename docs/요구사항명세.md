# 금오분식 POS 시스템 — 요구사항 명세

> 과제: 2.5 POS(Point-Of-Sale) 시스템
> 가게: **금오분식** (분식집) — 테이블 8개, 메뉴 16종(분식/김밥/면류/튀김·사이드/음료)
> 대상: **식당(테이블·포장 주문이 있는 음식점) 전용 POS**. 바코드 판매 위주의 편의점·마트 용도는 범위에서 제외한다.

이 문서는 다음 세 가지를 정리한다.

1. 과제의 **필수 요구사항**과 구현 위치
2. 직접 정의한 **제한사항**(업무 규칙)
3. 직접 정의한 **확장 기능**

## 2. 제한사항 (직접 정의한 업무 규칙)

모든 수치는 `pos/config.py` 상수로 관리하며, 위반 시 안내 메시지를 띄우고 처리를 거부한다.

### 주문
- 한 메뉴의 수량은 **1~99개**, 한 주문에 담을 수 있는 항목은 **최대 50줄**이다.
- 테이블은 **최대 30개**까지 등록할 수 있고, 좌석 수는 1~20이다.
- 한 테이블에는 진행 중인 주문이 **하나만** 존재한다(같은 테이블을 다시 누르면 기존 주문을 이어서 연다).
- **재고가 부족한 메뉴는 주문할 수 없다.** 주문 가능 수량 = 레시피 재료별 `재고 ÷ 1개당 사용량`의 최솟값.
- 수량을 줄이거나 주문을 취소하면 **조리 전(대기) 항목만** 재료가 복구된다. 이미 조리한 음식은 복구하지 않는다.
- 결제가 하나라도 진행된 주문(분할 결제 중)은 **메뉴를 추가·변경·삭제할 수 없고**, 테이블 이동·병합·분할도 불가하다.
- 아무 메뉴도 담지 않은 주문은 저장하지 않는다.

### 메뉴 옵션 · 요청사항
- 옵션은 **그룹 옵션**(예: 맵기 — 그룹 안에서 하나만 선택)과 **개별 옵션**(예: 치즈 추가 — 여러 개 선택)으로 나뉜다.
- 옵션 추가금은 **0~10,000원, 100원 단위**. 옵션 가격은 단가에 포함되며 메뉴 할인율도 함께 적용된다.
- 옵션에 재료를 지정하면(예: 곱빼기 → 라면사리 1개) **주문 시 재료가 함께 차감**되고, 그 재료가 없으면 해당 옵션은 선택할 수 없다(옵션 없이 기본 메뉴는 주문 가능).
- 같은 메뉴라도 **옵션이나 요청사항이 다르면 별도 항목**으로 담는다.
- 요청사항은 **40자 이내**이고, **조리 시작 전**에만 수정할 수 있다.
- 옵션은 삭제해도 지난 주문 기록을 위해 숨김 처리한다. 예약 주문에는 옵션을 붙일 수 없다.

### 주방 주문서 · 인쇄
- 주방 주문서는 **마지막 출력 이후 추가·취소된 수량만** 인쇄한다(처음은 "주방 주문서", 이후는 "추가 주문서"). 보낼 내용이 없으면 출력하지 않는다.
- 주문 화면에서 주방에 아직 안 보낸 항목은 상태가 **"미전송"**(파란색)으로 보인다.
- 인쇄는 운영체제 기본 프린터를 사용한다. 설정에서 끄거나 인쇄에 실패하면 `prints/` 폴더에 텍스트 파일로만 저장하고 안내한다.

### 할인
- 적용 순서: **메뉴별 할인 → 시간대 할인 → 쿠폰 → 포인트**.
- 할인 금액은 **10원 미만 절사**.
- 메뉴별 할인율은 0~50%, 시간대 할인율은 1~30%.
- 시간대 할인은 **주문 접수 시각** 기준이며, 여러 개가 겹치면 할인율이 가장 큰 **1개만** 적용한다. 요일 지정 가능.
- 쿠폰은 주문당 **1장**. 만료일·최소 주문 금액·최대 사용 횟수를 검사한다. 정률 쿠폰 1~50%, 정액 쿠폰은 100원 단위.

### 결제
- 분할 결제는 주문당 **최대 10회**.
- 결제 금액은 1원 이상, 남은 금액 이하.
- 현금은 받은 금액이 결제 금액보다 적으면 결제할 수 없다.
- **첫 결제 시점에 금액이 확정(잠금)** 되며, 이때 쿠폰 사용 횟수와 포인트가 차감된다. 이후에는 회원·쿠폰·포인트 변경 불가.
- 메뉴별 분할 결제 금액 = 선택 메뉴의 (메뉴할인 후) 금액 × (최종 결제액 ÷ 메뉴할인 후 총액), 10원 단위 반올림. 마지막 결제가 끝전을 정산한다. 이미 결제한 메뉴는 다시 선택할 수 없다.

### 회원 · 포인트
- 휴대폰 번호(010 등 01X로 시작, 10~11자리)는 회원별로 **중복 불가**.
- 등급(누적 결제액 기준): **일반 1% / 실버(30만원↑) 2% / 골드(100만원↑) 3%** 적립.
- 포인트는 **1,000P 이상, 100P 단위**로, 보유 포인트와 결제 금액 이내에서 사용한다.
- 포인트로 결제한 금액에는 포인트가 적립되지 않는다(실제 결제액 기준 적립).
- 탈퇴 시 포인트는 소멸한다. 진행 중인 주문이 있으면 탈퇴 불가.

### 취소 · 환불
- **주문 취소**: 결제 전 주문. 사용자 모드에서 가능.
- **결제 취소/환불**: 결제가 진행된 주문. **관리자 모드에서만** 가능하며 사유 입력 필수.
- 전체 환불 시 적립 포인트 회수, 사용 포인트 복원, 쿠폰 사용 횟수 복원, 회원 누적 결제액 차감. 재고 복구는 선택.
- **부분 환불**: 결제 완료 주문에서 메뉴·수량을 골라 환불한다.
  - 환불 금액 = 선택 메뉴의 (메뉴할인 후) 금액 × (실결제액 ÷ 메뉴할인 후 총액), 10원 단위 반올림. 주문 단위 할인(시간대·쿠폰·포인트)은 비율대로 나눈다.
  - 환불 수단을 고를 수 있고, 그 수단으로 낸 금액이 부족하면 나머지는 다른 결제수단에서 환불한다. 결제수단별로 낸 금액을 넘겨 환불할 수 없다.
  - 적립 포인트는 환불 비율만큼 회수하고(보유 포인트 한도 내), 사용 포인트와 쿠폰은 전체 환불 때 복원한다.
  - 남은 메뉴를 모두 환불하면 **전체 환불로 전환**된다. 이미 환불한 수량은 다시 환불할 수 없다.
- 환불액(전체·부분)은 **환불한 날의 매출에서 차감**한다(결제일 매출은 그대로 → 과거 마감 보고서와 불일치하지 않음).

### 시재(금전함 현금) 관리
- **예상 시재 = 개시 금액 + 현금 매출 − 현금 환불 + 입금 − 출금**. 현금 매출은 거스름돈을 뺀 결제 금액 기준이다.
- **시재가 개시된 상태에서만 현금 결제·현금 환불이 가능**하다(카드·간편결제·계좌이체는 무관). 각 현금 결제·환불은 당시 열린 시재에 기록된다.
- 시재는 **한 번에 하나만** 개시할 수 있다. 개시 금액은 0~1,000,000원, 10원 단위이며 기본값은 직전 정산 때 실제로 센 현금(이월)이다.
- 입금(잔돈 보충 등)·출금(재료 구입, 은행 입금 등)은 **사유 필수**, 10원 단위이며 **금전함 예상 현금보다 많이 출금할 수 없다**. 현금 환불도 금전함 예상 현금을 넘을 수 없다.
- **시재 점검(중간)**: 권종별(50,000·10,000·5,000·1,000·500·100·50·10원) 수량으로 실제 현금을 세어 과부족을 기록한다. 시재는 계속 열려 있으며 횟수 제한이 없다.
- **시재 정산(마감)**: 마지막으로 현금을 세어 시재를 닫는다. **과부족이 있으면 사유 필수**, 과부족이 **10,000원 이상이면 관리자 모드에서만** 정산할 수 있다. 정산 후에는 입출금·현금 결제가 불가하다.
- **시재가 열려 있으면 일일 마감을 할 수 없고**, 일일 마감 보고서에 그날 정산된 시재(개시·현금 매출·환불·입출금·예상·실제·과부족)가 포함된다.
- 시재가 열려 있으면 샘플 데이터를 생성할 수 없다(가상 거래가 실제 시재에 섞이지 않도록).

### 직원 · 급여
- 시급은 **2026년 최저시급 10,320원 이상**, 정직원 월급은 `10,320원 × 209시간` 이상이어야 한다.
- 정직원 통상시급 = 월급 ÷ 209시간.
- 1회 근무는 **최대 16시간**. 초과 시 퇴근 처리를 거부하고 관리자 수정을 요구한다(퇴근 누락 방지).
- 같은 직원의 근무 기록은 시간이 **겹칠 수 없다**.
- 아르바이트: `시급 × 근무시간` + **주휴수당**(ISO 주 기준 주 15시간 이상 근무한 주: `min(주 근무시간, 40) ÷ 40 × 8 × 시급`) + 일 8시간 초과분 0.5배 가산.
- 정직원: `월급` + **연장수당**(일 8시간 초과분 × 통상시급 × 1.5).
- 근무 중인 직원은 퇴사 처리할 수 없다.

### 예약
- 예약은 현재로부터 **30분 이후** 시각만 가능하다.
- 매장 예약은 테이블을 지정해야 하며, 같은 테이블에 **앞뒤 1시간 이내 중복 예약 불가**.
- 예약 시각 **10분 전**부터 알림. 재고 차감은 예약 등록 시가 아니라 **주문 전환 시점**에 한다.
- 예약 테이블에 다른 손님이 앉아 있으면 주문 전환 불가(먼저 비워야 함).

### 마감 · 보안
- **미결제 주문이 남아있으면 일일 마감을 할 수 없다.** 같은 날은 한 번만 마감(이후 재출력만 가능).
- 관리자 비밀번호는 **숫자 4~8자리**, 솔트+SHA-256 해시로 저장한다(초기값 `0000`).
- 비밀번호 **3회 오류 시 30초간 로그인 잠금**.
- **DB 복원**은 관리자만 가능하며, 복원 직전 상태를 자동 백업한 뒤 진행한다. POS 백업 파일인지(필수 테이블, 무결성) 검사하고, 이전 버전 백업이면 새 항목을 자동으로 추가한다. 복원하면 관리자 비밀번호도 백업 시점 값으로 돌아간다.
- 계좌이체는 실제 입금 확인 기능이 없으므로, 직원이 입금을 확인한 뒤 결제 처리한다.
- 메뉴·테이블·직원·회원은 삭제 시 실제로 지우지 않고 **비활성화**하여 과거 판매·급여 기록을 보존한다.

## 3. 확장 기능 (직접 정의)

| 기능 | 설명 |
|---|---|
| **Windows 실행 파일(exe) 배포** | PyInstaller 단일 exe(`KumohPOS.exe`). Python 없이 실행되며 데이터는 exe 옆 `data\` 폴더에 저장. 콘솔 창 없음, 전용 아이콘, 오류는 `data\error.log`에 기록하고 메시지 창으로 안내. |
| **데이터 영속 저장(SQLite)** | 모든 데이터를 `data/pos.db`에 저장. 프로그램을 껐다 켜도 진행 중 주문·통계가 유지된다. |
| **레시피 기반 재고 관리** | 메뉴마다 재료 사용량을 지정. 재고 화면에서 입고/폐기, 재료별 **재고 변동 이력** 조회. |
| **남은 수량 표시** | 메뉴 버튼에 재고로 만들 수 있는 남은 수량이 10개 미만이면 표시(주황색). |
| **주방 화면(KDS)** | 조리 대기열, 조리 시작/완료, 15분 이상 대기 항목 빨간 표시, 15초마다 자동 갱신. |
| **회원 등급제** | 누적 결제액에 따라 일반/실버/골드 자동 등급, 적립률 차등. 회원별 구매·포인트 이력. |
| **N명 균등 분할 계산** | "1/N 계산" 버튼으로 남은 금액을 남은 인원수로 나눈 금액(10원 단위 올림) 자동 입력. |
| **부가세 표시** | 영수증에 결제 금액 중 부가세(1/11) 표시. |
| **CSV 내보내기** | 통계 전체, 월 급여 명세를 엑셀에서 바로 열 수 있는 CSV(UTF-8 BOM)로 저장. |
| **DB 백업** | 설정 화면에서 현재 DB를 `backups/`에 시각별로 백업. |
| **작업(감사) 로그** | 로그인, 메뉴·재고 변경, 결제, 환불, 마감 등 주요 작업을 모드와 함께 기록·조회. |
| **샘플 데이터 생성기** | `python main.py --demo 60` 또는 설정 화면 버튼으로 과거 판매·근태 데이터를 생성하여 통계 기능 시연. |
| **노쇼/예약 취소 처리** | 예약 상태: 대기 → 주문전환/취소/노쇼. |
| **시재 관리** | 시재 개시·입출금·권종별 중간 점검·정산(과부족 사유, 관리자 승인 기준), 시재 정산서 인쇄, 최근 30일 정산 이력과 과부족 합계, 상단 바 시재 상태 표시, 일일 마감 보고서 연동. |
| **메뉴 옵션** | 맵기(하나 선택), 곱빼기·치즈/계란/사리 추가(복수 선택) 등 추가금 옵션. 옵션별 재료 차감, 관리자 화면에서 메뉴별 옵션 추가·삭제. |
| **요청사항 메모** | 메뉴별 "덜 맵게", "포장 따로" 같은 요청을 입력·수정. 주방 화면·주방 주문서에 표시. |
| **계좌이체 결제** | 결제수단에 계좌이체 추가. 결제 창에 입금 계좌 안내, 영수증·통계·마감 보고서에 반영. |
| **주방 주문서·영수증 인쇄** | 기본 프린터로 주방 주문서(추가분만), 영수증, 마감 보고서 인쇄. 설정에서 사용 여부·테스트 인쇄. |
| **부분 환불** | 메뉴·수량 단위 환불, 결제수단별 환불 배분, 통계·영수증 자동 반영. |
| **기간 비교 통계** | 선택 기간과 비교 기간(전월·전년·지난달 같은 날짜·직전 기간)의 순매출·건수·객단가·할인·환불·원가·순이익 증감과 메뉴별 증감. 요약 카드에 "비교 기간 대비 ±%" 표시. CSV에도 포함. |
| **DB 복원** | 백업 파일을 골라 복원(복원 전 자동 백업, 파일 검증, 구버전 자동 업그레이드). |
| **DB 자동 업그레이드** | 이전 버전으로 만든 `pos.db`도 실행 시 새 컬럼·테이블을 자동 추가하여 그대로 사용. |
| **단축키** | `F12` 관리자/사용자 모드 전환, 주방 화면 더블클릭 = 조리 완료. |
| **단위 테스트** | 업무 규칙 59개 테스트(`tests/test_pos.py`). |
